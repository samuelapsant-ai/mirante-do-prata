# Casa Mirante do Prata

Demonstração de site para a **Casa Mirante do Prata**, uma hospedagem de serra no Vale das Videiras, em Araras, Petrópolis/RJ. A página foi criada como proposta comercial e tem foco em apresentação da estrutura, galeria e consulta de disponibilidade via WhatsApp.

## O que a demonstração inclui

| Área | Função |
|---|---|
| Hero e identidade | Apresenta a casa e o destino com direção visual própria. |
| Informações práticas | Exibe capacidade, quartos, camas e banheiros. |
| Experiências | Destaca piscina, sauna, ofurô, churrasqueira, sinuca e vista para montanhas. |
| Galeria | Organiza imagens públicas autorizadas para a prévia. |
| Conversão | O formulário transforma dados da viagem em uma mensagem de WhatsApp. |

## Rodar localmente

```bash
pnpm install
pnpm dev
```

Para validar a produção:

```bash
pnpm check
pnpm build
```

## Observações da prévia

Os fatos e fotos usados na demonstração foram verificados em páginas públicas encaminhadas pelo proprietário. Antes da publicação definitiva, confirme a seleção final de imagens, telefone de reservas, texto institucional, políticas e qualquer integração de calendário.

As imagens referenciadas em `/manus-storage/` pertencem ao ambiente de prévia. Para um deploy externo independente, substitua-as por ativos finais autorizados e hospedados pelo cliente.
